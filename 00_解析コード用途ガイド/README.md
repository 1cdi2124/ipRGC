# 解析コードの用途・実行順（2026-10-06整理）

現在の主解析は `joint20261006.m` です。普段使うコードは「04　解析実行コード」の直下に残し、従来方式・旧版・バックアップを用途別に分離しました。解析コードの内容は変更していません。

## 通常の実行順

1. `saccade.m`：生データCSVからサッケードOnset付きSETを作成します。
2. 検出結果を目視確認し、必要な修正済みSETを被験者の `03_手動サッケード` へ置きます。
3. `joint20261006.m`：共通ICA → newtimef ERSP → NoGreen差分 → 帯域ERSP → 三要因ANOVA用CSVを一括作成します。
4. ICA-QC・ERSP・帯域結果を確認します。SPSSには `ANOVA_threeway_wide.csv` を使用します。

`saccade.m` はOnset基準、`lambda.m` は振幅頂点基準です。二つを順番に必ず実行するのではなく、解析目的に応じて使い分けます。

## MATLABでの使い方

まず「04　解析実行コード」をCurrent Folderにします。

```matlab
setup_analysis_paths
joint20261006
```

従来CWTを比較するときだけ、必要な用途フォルダを追加します。

```matlab
setup_analysis_paths("10_従来方式_CWT")
ICA_CWT_ERS_0702
```

他の用途も同様にフォルダ名を指定します。共通入力関数がある直下も同時に追加されます。
設定は現在のMATLABセッションだけで、EEGLABパスや解析パラメータは変更しません。
既存パスは削除しません。以前に旧フォルダを保存していた場合はMATLABの「パスの設定」で確認してください。

**`addpath(genpath(...))` による全フォルダ追加は避けてください。**
バックアップにはファイル名と関数名が一致しない版があり、検討用の `time.m` は他の関数と名前が衝突する可能性があります。
